# Power BI data exports

Every CSV in this folder is generated by:

```bash
python -m src.dashboard_export
```

The export is **not committed** to the public repository because it is derived from the Kaggle competition data, whose terms do not allow redistribution. Running the command recreates:

| File | Grain | Rows |
|---|---|---:|
| `dim_store.csv` | store | 1,115 |
| `dim_date.csv` | day | 990 |
| `fact_sales.csv` | store-day | 1,017,209 |
| `agg_store.csv` | store | 1,115 |
| `agg_daily.csv` | day | 942 |
| `agg_weekday.csv` | weekday | 7 |
| `agg_promo.csv` | promo x store type | 8 |
| `model_metrics.csv` | fold x model | 20 |
| `forecast_holdout.csv` | store-day (XGBoost holdout) | 52,405 |
| `forecast_test.csv` | store-day (competition forecast) | 41,088 |

Import these into Power BI Desktop following `dashboard/dashboard_specification.md`.
